Three minutes

Up and running before your coffee cools.

01

Get .NET 8

Install the .NET 8 SDK for Windows x64 (the SDK, not just the runtime), then restart your terminal.

winget install Microsoft.DotNet.SDK.8
02

Build & run

From the Island folder. Hover the black pill at the top of your primary display.

PS> dotnet build PS> dotnet run
03

Plug in your accounts

Right-click the tray icon, open Settings, then paste a restricted Stripe key or Polar token and connect Google. Make it a single .exe whenever you like.

dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
